# Goal Rules

**Скилл для режима `/goal` в Claude Code, с которым ИИ-агент доводит длинную задачу до конца, пока вас нет, не останавливаясь и не выходя за рамки.**

Goal Rules это скилл для автономной работы в Claude Code, Codex, OpenCode, Cursor и других
агентах, которые понимают Agent Skills. Он включается на задачу через `/goal` или когда вы отдаёте
задачу и уходите, какими бы словами это ни было сказано. "Сделай всё до конца, ничего не
спрашивай, вернусь и проверю."

## Зачем

Когда некому ответить, всё ломается одним из двух способов.

- Агент останавливается на первом непонятном месте с вопросом, на который никто не ответит, и всё
  отведённое время пропадает.
- Или решает всё сам, включая то, что вы бы никогда не разрешили. Пуш в релизную ветку, миграцию
  на живой базе, удаление файла за пределами задачи.

Эти правила находятся между двумя крайностями. Каждое открытое место становится записанным
решением, а короткий список действий остаётся под запретом, как бы удобно это ни было.

## Установка

| Агент | Команда |
|---|---|
| Claude Code, как плагин | `/plugin install goal-rules --marketplace nyxandro/skills` |
| Claude Code, Codex, OpenCode, Cursor и другие | `npx skills add nyxandro/goal-rules-skill` |
| Любой агент, вручную | Скачайте [архив `.skill` последнего выпуска](https://github.com/nyxandro/goal-rules-skill/releases/latest/download/goal-rules.skill) и распакуйте в папку скиллов агента |

Выберите один способ. Если поставить двумя, Claude Code загрузит скилл дважды.

<details>
<summary>Другие способы установки</summary>

<br>

- Установка плагина одной командой работает в Claude Code 2.1.275 и новее. На старой версии
  сначала добавьте каталог командой `/plugin marketplace add nyxandro/skills`, потом выполните
  `/plugin install goal-rules@nyxandro`.
- Версия в каталоге не закреплена, поэтому каждый коммит сюда приходит пользователям плагина как
  обновление. Выполните `claude plugin marketplace update nyxandro` и
  `claude plugin update goal-rules@nyxandro` или включите автообновление в
  `/plugin` → Marketplaces.
- С `npx skills` добавьте `-g`, чтобы скилл стоял во всех проектах. Чтобы поставить определённую
  версию, допишите её метку, например `nyxandro/goal-rules-skill@v1.0.0`.
- Можно и клонировать репозиторий, а в папку скиллов агента положить ссылку на папку
  `goal-rules/`. Скилл это один файл `SKILL.md`, без скриптов и сборки.

</details>

## Как пользоваться

Поставьте задачу через `/goal` и уходите. Обычные слова тоже работают.

- *Ставлю длинную задачу и отхожу от компьютера. Ничего не спрашивай.*
- *Просто иди и сделай всё до конца.*
- *Если что-то непонятно, реши сам и запиши.*
- *Работай самостоятельно, вернусь и проверю.*
- *Прогони это ночью.*

## Как работает

1. Агент начинает сразу. Не пересказывает задачу на подтверждение, не показывает план на
   одобрение, не спрашивает "можно начинать?".
2. Каждый вопрос превращается либо в решение, которое агент принимает сам, либо в блокер, который
   он записывает. Открытое место решается по тексту задачи, потом по документации проекта, потом
   по соглашениям в коде, а в последнюю очередь самым осторожным вариантом, который легко
   откатить. Каждое решение записывается с вариантами и причиной выбора.
3. Никогда сам не пересекает стоп-лист. Разрешить пункт может только текст задачи, прямо и по
   названию.
4. Пользуется короткими простыми командами в терминале. Длинные составные команды как раз и
   блокирует проверка разрешений, а одобрить их некому. Заблокированную команду агент
   переписывает проще и никогда не обходит.
5. Работает в своей ветке, коммитит после каждого значимого шага, гоняет проверки проекта
   соразмерно правке, доделывает всё, что не заблокировано, и не расширяет задачу.
6. Пишет отчёт по ходу, с первого шага, поэтому сжатие контекста или упавшая сессия ничего не
   теряют.

## Стоп-лист

| Никогда сам | Можно по умолчанию |
|---|---|
| Пуш в релизные и защищённые ветки, любой деплой | Коммиты в свою рабочую ветку |
| Force-push, переписывание общей истории, удаление чужих веток | Локальные тесты и линтеры |
| Миграции и запись в живые базы, разрушительные операции с данными | Правки в рамках задачи |
| Изменение конфигурации, секретов и файлов на серверах | Чтение всего, что можно читать |
| Удаление или переписывание файлов за пределами задачи | |
| Отмена и перезапуск задач CI | |
| Pull request, задачи в трекере, сообщения людям, любые публикации | |
| Траты на сервисы, аккаунты, тарифы и ключи API | |

## Пример

Итоговый отчёт выдуманного прогона, сокращённый.

```text
Outcome. Done partially. The CSV export works, emailing it is blocked.

Done
  a1b2c3d  Export endpoint and button, 14 tests pass
  d4e5f6a  Large exports run in the background, 3 tests pass

Decisions taken on my own
  Date format is ISO 8601, because the existing JSON export already uses it.

Blockers
  Emailing the file needs SMTP credentials. Add SMTP_URL and say "send it".

Check this first
  Admin, then Orders, then Export CSV on any date range.

Next step
  Turn on emailing once SMTP is set.
```

Когда вы вернётесь и спросите, что было, агент ответит в пяти-семи строках по отчёту. Следующий
шаг за вами.

## Версии

Текущая версия записана в поле `metadata.version` файла `goal-rules/SKILL.md`, так что любая
установленная копия показывает, какая она. У каждой версии есть метка в git и
[выпуск](https://github.com/nyxandro/goal-rules-skill/releases) со своим архивом.
[CHANGELOG.md](CHANGELOG.md) рассказывает, что изменилось.
